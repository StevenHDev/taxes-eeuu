# Mejora de la plataforma

Aquí van los análisis, los ejemplos y las observaciones para mejorar la plataforma, de modo que cumpla con lo que se quiere: **entender al cliente → preguntar según lo que responde → pedir solo lo necesario → llenar los anexos → entregar un buen 1040**. El alcance es persona natural, incluidos los independientes con Schedule C, y una sola firma (GTS).
